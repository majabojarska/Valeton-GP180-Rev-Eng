This directory contains the result of tedious, manual USB captures of USB comms between the Valeton Suite, and the GP-180 unit. It exercises the full range of device controls, some of them triggered from either source (from Win10 or GP-180). The captures are intended to be used as a reference for reverse engineering the GP-180 SysEx protocol, and to verify that any implementation of the protocol is correct.

Device-triggered operation captures are prefixed with `device-triggered-`, and Suite-triggered operation captures are prefixed with `suite-triggered-`. The captures are in pcapng format, and can be opened in Wireshark. The captures are named according to the control exercised, and the values set. For example, `suite-triggered-effect-AMP-AC_Pre-Gain-sequence-21-50-77-unit-percent.pcapng` is a capture of the Suite changing the Gain parameter of the AC Preamp effect in the AMP module, from 21% to 50% to 77%, with the unit being percent.
